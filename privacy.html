Privacy Policy

ProInfra for Autodesk Civil 3D — published by NAHL Labs
Last updated: 14 October 2026

Summary: ProInfra does not collect, store or transmit any personal data. There is no telemetry, no analytics, no usage tracking, no account and no registration. Every command runs locally on your computer and works only on the drawing you have open. The plugin makes exactly one kind of outbound request: it checks for and downloads its own updates, as described below.

1. What data we collect

None. We do not collect or receive:

  • personal or contact information;
  • drawings, designs, project data or any file contents;
  • usage statistics, command history, crash reports or diagnostics;
  • licence keys, machine identifiers, IP-based profiles or user accounts.

We operate no server, no database and no logging facility that could receive such data.

2. Internet access: updates only

ProInfra includes a built-in updater so you receive fixes and new tools. This is the only feature that reaches the internet.

  • What it contacts: two files hosted on Dropbox — a small manifest listing available tool versions and, only when an update is selected, the update package itself.
  • What is sent: nothing beyond what any web request necessarily contains. The request is an anonymous HTTPS GET for a public file. No identifiers, drawing data or personal information are included.
  • When it runs: when you click Update in the ProInfra ribbon and — if the automatic option is enabled — a background check at most once every seven days when Civil 3D starts.
  • How to disable it: turn off Auto check & update in ProInfra → Settings. The plugin then makes no network requests at all unless you press Update yourself.

Dropbox serves these files and, like any web host, keeps its own server logs outside our control. We have no access to those logs and receive no reports from them.

3. Data stored on your computer

ProInfra writes small files inside its own installation folder. They stay on your machine, are never transmitted and are removed when you uninstall the plugin.

FilePurpose
settings.jsonYour ribbon preferences and whether automatic update checks are enabled
<tool>.verThe installed version of each tool, so the updater knows what is current
managed.txtWhich tools came from the update package, so tools you added yourself are never touched
autoupdate.txtThe date of the last update check, so it runs no more than weekly
ProInfra_log.txtLocal diagnostic messages to help you troubleshoot; not sent anywhere

4. Your drawings and project data

All commands run inside Autodesk Civil 3D on your computer. Drawing contents, model data and project files are read only to perform the command you ran, and are never uploaded, copied or shared.

5. Third parties

We do not use advertising networks, analytics providers or third-party SDKs, and we do not sell, rent or share data, because we hold none.
